# Microeconomics — Interactive Plates

Two self-contained interactive teaching decks for the CUNEF microeconomics course.

- **Utility Maximization** — nine plates: bang per buck, the equimarginal principle,
  indifference curves and the MRS, the budget constraint, the tangency condition,
  perfect substitutes, the individual demand curve.
- **Profit Maximization** — ten plates: MR = MC, marginal revenue under market power,
  monopoly equilibrium, surplus and deadweight loss, the short-run output decision,
  supply, competitive equilibrium.

Each page is a single HTML file with no build step and no dependencies beyond the
Taviraj webfont. All figures are hand-drawn SVG that recompute from the controls.
`localStorage` is used only to remember the light/dark preference.

Published with `noindex`: reachable by link, kept out of search results.
